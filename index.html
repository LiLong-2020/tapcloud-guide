02 · 中文使用教程

注册后如何导入 Tapcloud 订阅

iOS

Shadowrocket 导入订阅

  1. 注册并登录 Tapcloud，进入用户中心。
  2. 复制你的订阅链接或按照后台提示一键导入。
  3. 打开 Shadowrocket，添加订阅或配置。
  4. 更新订阅后选择可用节点，再开启连接。
Windows / macOS

Clash Verge 导入订阅

  1. 安装适合系统版本的 Clash Verge 客户端。
  2. 在 Tapcloud 后台复制订阅地址。
  3. 进入 Clash Verge 的 Profiles / 配置页面，粘贴订阅地址。
  4. 更新配置，选择节点和规则模式后测试访问。
Android

Clash for Android 导入订阅

  1. 安装 Clash for Android 或官方推荐的兼容客户端。
  2. 从 Tapcloud 后台复制订阅链接。
  3. 在客户端中新建配置，粘贴订阅 URL。
  4. 更新订阅，选择节点后开启 VPN 连接。

不同客户端版本的菜单名称可能略有差异，遇到连接失败时优先检查订阅是否过期、系统权限是否允许 VPN、节点是否可用。

04 · 常见问题

Tapcloud 中文 FAQ

Tapcloud 怎么注册？

可以点击页面顶部的 Tapcloud 邀请码注册链接，进入 Tapcloud 页面后按官方流程注册。具体套餐和付款规则以官方后台为准。

注册后第一步做什么？

先登录 Tapcloud 用户中心，查看套餐、订阅链接和官方说明，再按你的设备选择对应客户端导入。

订阅链接是什么？

订阅链接通常用于让客户端自动获取节点配置。它属于个人敏感信息，不要公开发布或分享给陌生人。

连接失败怎么办？

可以依次检查：套餐是否有效、订阅是否已更新、客户端 VPN 权限是否开启、当前节点是否可用、网络是否限制连接。

流量、退款、套餐怎么确认？

这类问题以 Tapcloud 官方后台、官方公告或客服回复为准。本页面不代替官方售后。
